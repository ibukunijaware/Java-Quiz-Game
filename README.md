# Quiz Game 
## Description 
A Java-based quiz game application with a graphical user interface developed using Java Swing.
The application allows players to answer questions and get scored through an interactive interface.
The project was developed to practice Java programming, Object-Oriented Programming and Graphical User Interface development. 

## Features 
-Interactive graphical user interface. 
- Ask 10 multiple-choice quiz questions.
- Tracks the player's score.
- Display the final result.
- Start, quiz, and result screens.
- User-friendly navigation.

## Technologies Used 
-Java.
-Java Swing.
- Object-Oriented Programming (OOP).

## How to run 
1. Clone this repository.
2. Open the project in a Java IDE.
3. Run the main GUI class.
4. Follow the instructions displayed in the screen.

## Project Structure 
- 'Questions.java' - Represents quiz questions.
- 'QuizManager.java' - Manages quiz questions and game logic.
- 'ScoreManager.java' - Handles score tracking.
- 'QuizGame.java' - Main entry point for the quiz game.
- 'MainGUI.java' - Main GUI window.
- 'StartPanel.java'-Starting screen.
- 'QuizPAnel.java'- Displays quiz questions and answer options.
- 'ResultPanel.java'-Displays the player's final score.
